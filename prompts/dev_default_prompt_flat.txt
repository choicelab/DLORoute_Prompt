You should command Pull when the rope head can be grasped from the exit direction of the current clip and initialize insertion for the next clip.
The Flatten action will reorient the rope head and roughly align the rope head with the current clip open direction. 
You should command Flatten when Insert are executed multiple times but rope is still not inserted. The Flatten action will reinitialize the rope head for current clip insertion.
